Internal tool concept

Tank Status Communication Web App

A shared operational interface for checking tank requirements, fulfilment status, ownership, and follow-up actions.

Operations / Tool Designer Google Apps Script · Google Sheets · Shared Web Interface
▶ View Case Study Back to Projects

The problem

Tank readiness can affect whether a scheduled service visit can proceed, but status information can be scattered across emails, spreadsheet notes, purchasing updates, and verbal follow-ups. The tool concept creates one simple place to see what is required and what remains unresolved.

How it works

Step 01

Open one shared web app

The Apps Script deployment is designed around a simple shareable web-app URL, avoiding a heavier sign-in workflow for routine internal use.

Step 02

Read the Sheet-backed records

The interface loads Tank Jobs, inventory requirements, communication history, status fields, owners, dates, and notes from the connected Google Sheet.

Step 03

Update status and communication

Users can record current quantities, readiness, follow-up notes, next actions, and communication history so the operational view stays current.

Step 04

Preserve accountability

A change log keeps important updates traceable, while scheduling staff can use the current tank status before confirming or maintaining a service visit.

Design approach

  • Kept the Google Sheet as the underlying operational record while adding a cleaner web interface.
  • Designed for a single shareable URL rather than introducing a separate account system.
  • Separated jobs, communications, inventory, settings, and change history so users can quickly find the information they need.
  • Avoided marking items fulfilled unless the available evidence supported that status.

Outcome

A lightweight internal web-app concept that makes tank readiness, inventory, communication, and next actions easier to see in one place and easier to use when coordinating service work.

What this demonstrates

Google Apps Script web-app design, Google Sheets integration, operational status tracking, change logging, dependency management, and cross-functional communication.
