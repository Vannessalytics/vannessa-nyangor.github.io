Working project

Google Apps Script Locator

A lightweight search-and-locate interface for operational information stored in Google Workspace.

Workflow / Tool Designer Google Apps Script · Google Sheets · Web App
▶ View Case Study Back to Projects

The problem

Operational scheduling becomes harder when customer and system-location records are incomplete or inconsistently formatted. This Apps Script tool enriches missing location data so scheduling, proximity checks, and routing can use cleaner address information.

How it works

Step 01

Read the operational record

The script starts from a Google Sheet row and checks the available System Location or Customer information for the job or service record.

Step 02

Resolve the location

Google Places / text search and geocoding logic are used to identify the best matching location when address fields are missing or incomplete.

Step 03

Write standardized fields

The sheet is updated with formatted address, city, province, postal code, coordinates, Place ID, and a map link; unresolved records are clearly marked for review.

Step 04

Support scheduling decisions

The enriched location data can then support Ontario-only filtering, proximity grouping, route planning, and more reliable calendar preparation.

Design approach

  • Kept Google Sheets as the working operational source rather than introducing a separate database.
  • Used Google Apps Script to connect existing records with location and geocoding services.
  • Made unresolved lookups visible instead of silently inserting uncertain location data.
  • Structured the output so addresses and coordinates can be reused by later scheduling and mapping workflows.

Outcome

A lightweight location-enrichment workflow that turns incomplete operational records into more consistent scheduling inputs while preserving a clear manual-review path when a location cannot be resolved.

What this demonstrates

Google Apps Script, Google Sheets automation, geocoding and Places integration, data normalization, operational exception handling, and location-aware workflow design.
