# Vannessa Nyang’or — Operations & Systems Portfolio

A static GitHub Pages portfolio with a dark, cinematic interface and no build step.

## Easy editing

Routine media updates are centralized:

- Replace `vannessa-profile.png` for the About-page portrait.
- Replace any project PNG using the same filename for project cover art.
- Replace project YouTube URLs in `site-config.js`.
- Add LinkedIn / GitHub links in `site-config.js`.

See `MEDIA-GUIDE.txt` for exact filenames and image dimensions.

## GitHub Pages

Publish the `main` branch from `/ (root)`.
All files are intentionally kept at repository root level. There are no nested folders and no framework/build step.

## Project case studies

The site includes individual case-study pages for:

1. Real Estate Multi-Platform Publisher
2. Google Apps Script Locator
3. Ontario Service Scheduling System
4. Tank Status Communication Web App
5. Invoice Automation

Each case study includes the problem, a short step-by-step workflow, design approach, outcome, capabilities demonstrated, project imagery, and an embedded demo-video area.
